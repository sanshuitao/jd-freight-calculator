# 京东快运运费计算器

> 纯前端静态网页计算器，适配手机微信浏览器，用于快速计算北京始发京东重货标快运费，支持体积重、多件货物、保价、上楼费、本地历史记录。
> 无需后端服务，所有计算逻辑在浏览器本地完成，历史记录保存在浏览器 localStorage，不上传服务器。

## 🧮 报价计算链路

1. **计费重量** = max(实际重量, 体积重量)，按 1KG 向上取整
   体积重量(KG) = 长(cm) × 宽(cm) × 高(cm) × 件数 ÷ **4000**（内部抛比系数；价格本官方规则为 ÷6000）
2. **基础运费**：首重 15KG + 续重①（15-60KG】 + 续重②（60KG 以上）分段累加，结果四舍五入取整
3. **附加服务**（可选）：
   - 保价费 = 保价金额 × 6‰，最低收费按计费重量分档（<40KG≥2元 / 40~100KG≥4元 / >100KG≥12元）
   - 上楼费：任意单件≥60KG 按 0.9元/KG；所有件<60KG 且整票≥100KG 按 0.3元/KG；单件>135KG 或超长不支持
4. **成本合计** = 基础运费 + 保价费 + 上楼费
5. **默认加价**：成本合计先 × (1 + 5%)（代码常量 `DEFAULT_MARKUP`，与利润率独立）
6. **最终报价** = 加价后成本 × (1 + 使用人填写的利润率%，默认 15)

## 🌐 部署（GitHub Pages）

- 仓库根目录放 `index.html`，GitHub 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`
- 访问地址：`https://<用户名>.github.io/<仓库名>/`
- 页面已内置 description / og 标签，微信内发送链接会显示标题与摘要卡片
